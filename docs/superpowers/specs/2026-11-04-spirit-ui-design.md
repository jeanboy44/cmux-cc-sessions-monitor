> **최종 결정 (아래 본문보다 우선)**: 카드는 20×9칸이다. 몸은 왼쪽, 마법은 오른쪽에 그린다. 컨텍스트 사용량은 몸이 아니라 마법의 크기를 정한다. 얼음(ice)은 독(poison)으로 바뀌었다. 캐릭터는 모델별이며 기본값은 fable=물, opus=불, sonnet=번개, haiku=독이고 설정(`model_themes`)에서 바꾼다. 카드별 `t` 키와 `card_themes`는 없다.

# 정령(spirit) 카드 UI 설계

이 문서는 `2026-11-04-pixelfx-ui-design.md`를 대체한다. 사용자가 pixelfx 원본 포팅(24×38 스프라이트, 이미지 출력 시안 포함)을 모두 보고 "못생겼다"고 판단해, 방향을 "눈이 점 두 개인 둥근 정령(고오스 형상)"으로 바꿨다. 정령의 몸이 속성(불·물·얼음·전기)에 따라 바뀐다.

## 의도

세션 목록을 훑다가 "어느 세션이 일하는 중인지, 입력을 기다리는지"를 정령의 움직임만으로 알아챈다. 카드는 작고 단순해야 한다(사용자 요구: "더 작게").

## 목표

- 카드마다 정령 한 마리(점자 점, 칸마다 24비트 색, 눈은 점 두 개). 기본 크기는 약 11칸 × 5줄(22×20 서브픽셀)이며 시안(`ghost_demo`, 17×7칸)을 축소한 것이다. 크기는 한 상수(`SPIRIT_SCALE`)로 조절한다.
- 속성 4종: fire, water, ice, lightning. 몸 형태·색·입자가 속성마다 다르다(시안 참고: 불=솟는 불꽃 혀, 물=광택 + 물방울, 얼음=각진 결정 + 반짝임, 번개=지글거리는 외곽 + 아크). melee는 제거한다.
- 상태: RUNNING=몸이 거칠게 일렁이고 마법 입자를 랜덤하게 오른쪽으로 쏨, NEEDS_INPUT=큰 눈 + 떠오르는 `?` + 맥동, IDLE=졸린 가로선 눈 + 천천히 둥둥 + z, DONE=웃는 눈(^ ^) + 반짝임, UNKNOWN=어둡게 정적.
- 컨텍스트 사용률에 따라 정령과 마법의 크기가 변한다(낮음 0~30% 작게, 중간 보통, 70% 이상 크게, 90% 초과는 붉은 경고 깜빡임). 사용률은 상태줄 스크립트가 `~/.cache/cmux-magigent/ctx/<세션id>.json`(`{"session_id","used_percentage"}`)에 써 주는 값을 읽는다(이미 설치됨). 파일이 없거나 오래되면(수 분 이상) 세션 기록 `~/.claude/projects/<폴더>/<세션id>.jsonl` 끝부분(마지막 수십 KB)에서 마지막 `usage`(input + cache_read + cache_creation 토큰)를 읽어 설정값 한도(기본 200,000)로 나눈 값을 쓴다.
- 테마는 설정에서 기본값, 선택한 카드에서 `t` 키로 카드별로 바꾼다(프로젝트 cwd 키, 비면 세션 id).
- 기존 동작 유지: 세션 정보 줄(이름, 상태, 브랜치, PR, 요약), 창 그룹 구분선, h/l/j/k 이동(h/l은 행 넘김), `p` 미리보기(한 줄 카드), HUD, 설정, cmux 파랑 선택 테두리.

## 비목표

- pixelfx 엔진 포팅은 하지 않는다(커밋 이력에 남은 포팅 코드는 정리하며 제거). 더미·마법 대상은 없다. 이미지(Kitty) 출력은 하지 않는다.
- 정령이 상태 구분을 가리면 실패다: 상태는 눈 모양과 움직임으로 항상 구분돼야 한다. CPU를 과하게 쓰면 실패다: 보이는 카드만 약 15fps로 그린다.

## 제약

- Rust 2021, rust-version 1.89, 새 크레이트 없음. macOS 전용. 개인정보 가드 통과(홈 경로·실제 UUID·회사명 금지). 문서는 한국어(내부), README는 영어로 별도 작업.

## 빌더에게 맡기는 것

- 정령의 정확한 모양·팔레트·입자 값, 크기 단계(작게/중간/크게)의 배율, 애니메이션 속도, 설정 UI 세부, 컨텍스트 파일 신선도 기준(제안: 5분).
